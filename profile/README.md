# REA4V-Lab

Independent software lab run by [**EmanuelPlaysDev**](https://github.com/EmanuelPlays). Fabric mods, Forge Mods, Spigot & Paper plugins — built solo.

---

### What this org is

REA4V-Lab is where solo projects get published once they're actually worth shipping. All made by a single person

The recurring shapes of the work:

- **Fabric Modding** — client and server-side Minecraft mods: HUD overlays, custom mechanics, config-driven features built to survive version bumps
- **Forge Modding** - client and server-side Minecraft mods: overlays and more

### Featured

[SpigBan](https://github.com/REA4V-Lab/SpigBan)** — an all-in-one punishment management plugin for Spigot/Paper 1.21.x. Bans, temp-bans, IP-bans, mutes, warns, and a full case-history system with sequential `SPGB-XXXXXX` case IDs. SQLite/MySQL backend, LuckPerms integration.
